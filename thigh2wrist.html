About this view

The points use UMAP (Uniform Manifold Approximation and Projection), which places many-dimensional movement features on a two-dimensional map. The same map is used across the three panels. The animation interpolates between each recording's projected before-and-after positions. Intermediate frames illustrate the change and are not model trajectories.

Activity recognition results

Results use the complete test set and stay fixed when display filters change. Rows show recorded activities. Columns show predictions. Macro-F1 gives each activity equal weight when summarizing precision and recall.

Reference recordings guide training. Prediction uses wrist input alone.
